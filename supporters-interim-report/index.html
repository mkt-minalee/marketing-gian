회사가 매월 주력게임을 지정하고, 해당 게임 활동 시 우수활동 점수에 가산

활동 커뮤니티: 인벤 · 디시인사이드 반반주간 활동량을 인벤과 디시인사이드에 절반씩 나눠 활동. 게시글 3건 + 댓글 15건 기준 커뮤니티별 게시글 1건 + 댓글 7건 이상, 댓글 대체로 게시글 4건 + 댓글 10건 진행 시 커뮤니티별 게시글 2건 + 댓글 5건. 한쪽 커뮤니티 기준을 채우지 못한 주는 주간 기준 미충족.

팀 전체 활동량은 주 180건(10명 × 18건). 5개 게임에 나뉘면 게임당 평균 주 게시글 6건·댓글 30건으로, 한 게임에 5명이 집중될 때(게시글 15건·댓글 75건)의 40% 수준. 특정 게임에 홍보성 활동이 반복되는 부담 완화.

사전 고지

아래 내용을 모집 공고·지원폼·합격 안내 3곳에 같은 문장으로 반복 고지하고, 지원폼에서는 필수 동의로 확인. 무보상 테스트는 반발 우려가 있어 1주 테스트는 도입하지 않음.

  1. 활동 기간 8주(11월~12/26)를 끝까지 참여합니다
  2. 주간 기준은 게시글 3건 + 댓글 15건이며, 인벤과 디시인사이드에 절반씩 나눠 활동합니다(커뮤니티별 게시글 1건 + 댓글 7건 이상). 매주 일요일까지 시트에 링크를 기록합니다
  3. 활동비는 월 단위로 판정합니다. 기준을 채운 달은 지급되며, 기준을 채우지 못하거나 중도에 활동을 중단한 달은 지급되지 않습니다예: 11월 기준 충족 후 12월 중단 시 11월분만 지급
  4. 우수활동비는 8주를 모두 기준대로 활동한 사람만 대상이며, 2개월 활동을 합산해 1인 1상으로 선정합니다. 기준을 충족한 활동자가 없으면 지급되지 않습니다
  5. 직접 확인한 경험과 사실만 작성하고, 게시판 규칙을 지키며, 다른 거래 사이트를 언급하거나 비교하지 않습니다
