## 🗂 파일 규칙

- 문서 파일명: `번호_문서제목.html` (예: `03_○○기획안.html`)
- 새 문서를 추가하면 위 목록과 `index.html`에도 링크를 추가합니다.

## ✏️ 새 기안 올리는 방법 (웹에서)

1. 이 저장소에서 **Add file → Upload files** 클릭
2. HTML 파일을 끌어다 놓기
3. 아래 **Commit changes** 클릭 (커밋 메시지에 무엇을 올렸는지 간단히 기록)
